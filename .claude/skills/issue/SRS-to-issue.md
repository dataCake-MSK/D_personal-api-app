# SRS 항목 → 이슈 본문 형식

```markdown
### 추적 ID
NB-xxx → PRD-xxx → SRS-xxx

### 작업 내용
(SRS 항목의 내용)

### 수용 기준 (AC)
- [ ] ...

### 메모 / 제약
- 문서: docs/requirements/SRS.md#srs-xxx
```

라벨 매핑:
- 기능 → `type:feature`, 버그 → `type:bug`, 문서 → `type:docs`, 설정/CI → `type:chore`
- 위젯 관련 → `area:widget`, 대시보드 → `area:dashboard`, 빌드/CI/저장소 → `area:infra`
- M0 항목 → 마일스톤 `M0 기반`, M1 → `M1 MVP`
