# ADR-0002 MVP는 백엔드 없이 앱에서 외부 API 직접 호출

- 상태: 승인
- 날짜: 2026-09-16
- 관련: PRD-002, PRD-004, PRD-006, NB-005

## 맥락
장기적으로 AWS 운영을 고려하지만, MVP는 1인 사용자이며 빠른 검증이 우선이다.

## 결정
앱이 외부 API를 직접 호출한다. 대시보드 구성은 기기 로컬, API 키는 `expo-secure-store`에 보관한다.

## 대안
- 초기부터 AWS 백엔드(API Gateway + Lambda 등): 키 보관·주기 수집·동기화에 유리하나 초기 복잡도·비용 증가.

## 결과
- 서버 비용·운영 부담 없음, 개발 속도 빠름.
- 감수: 기기 간 동기화 불가, 앱이 켜져 있을 때만 데이터 수집, CORS는 네이티브 앱이라 문제 없음(웹 빌드 제외).
- 재검토 조건: 백그라운드 수집, 다기기 동기화, 키를 기기에 두면 안 되는 API가 필요해질 때.
