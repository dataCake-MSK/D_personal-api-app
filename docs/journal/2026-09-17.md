### 처음 받아서 실행
```bash
git clone https://github.com/dataCake-MSK/D_personal-api-app.git
cd D_personal-api-app
npm ci
npx expo login                 # Expo Go와 같은 계정
npx expo start --tunnel --go   # 폰 Expo Go 홈의 개발 서버 목록에서 열기
npx tsc --noEmit               # 타입 검사
```
- 같은 Wi‑Fi면 `npx expo start`(LAN)도 가능. 폰에서 QR 스캔.
