### 핵심 코드·설정
- 위젯 정의에 설정 입력 UI 추가 (`src/widgets/types.ts`)
```ts
export type WidgetDefinition<TConfig = unknown> = {
  type: string; label: string;
  configSchema: ZodType<TConfig>;
  Renderer: ComponentType<WidgetRendererProps<TConfig>>;
  ConfigEditor: ComponentType<WidgetConfigEditorProps>;
  defaultConfig: Record<string, unknown>;
};
```
- 화면에서 저장소 사용 (`src/app/index.tsx`)
```tsx
const widgets = useDashboardStore((state) => state.widgets);
const addWidget = useDashboardStore((state) => state.addWidget);
```
- RNTL 14 테스트: `render`와 `fireEvent` **모두 await**
```tsx
await render(<DashboardScreen />);
await fireEvent.press(screen.getByText('+ 위젯 추가'));
```
