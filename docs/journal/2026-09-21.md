### 핵심 진행사항
1. **위젯 수정**: 추가용 모달(`widget-form-modal.tsx`)을 추가·수정 겸용으로 일반화. 카드의 "수정" → 기존 설정이 채워진 상태로 열림 → 저장 시 위젯 id·순서 유지

### 핵심 코드
```tsx
// src/app/index.tsx — 열 때마다 새 모달
const openForm = (widgetId: string | null) => {
  setEditingId(widgetId);
  setFormKey((key) => key + 1);
  setFormOpen(true);
};
<WidgetFormModal key={formKey} visible={formOpen} editing={editing} … />
```
