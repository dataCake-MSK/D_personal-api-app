### 핵심 명령
```bash
# 훅 스크립트 단위 확인 (저장소 루트에서)
echo '{}' | node .claude/hooks/stop-vcs-check.js                        # 깨끗하면 출력 없음, 종료 0
printf x > .tmp && echo '{}' | node .claude/hooks/stop-vcs-check.js     # {"decision":"block",…} 출력
echo '{"stop_hook_active":true}' | node .claude/hooks/stop-vcs-check.js # 통과(무한 반복 방지)
rm .tmp
```
- 실제 등록 확인: 변경을 커밋하지 않은 채 턴을 끝내면 훅이 종료를 막는다.
- 훅은 **세션 시작 시 읽힌다.** 설치한 세션에서는 적용되지 않으므로 재시작 후 확인한다.
