## 개발자 퀵 가이드
> 이날 결과로 이어진 진행사항만 압축. 시행착오는 제외(→ 막힌 점, 학습 노트).

### 핵심 진행사항
1. **시계열 변환**(`src/widgets/http-json/timeseries.ts`): 값 배열 + 시간 배열, 또는 객체 배열 + 필드 지정 두 가지를 모두 점 배열로 변환. 숫자가 아닌 항목은 제외, 라벨은 간격을 두고 솎아냄
2. **그래프 뷰**(`chart-view.tsx`): `react-native-gifted-charts` 선 그래프 + 개수·최소·최대 요약
3. **설정 확장**: 표시 형식에 "그래프", 시계열용 `xPath`·`yField`·`xField` 입력

### 핵심 명령
```bash
# Expo Go 호환: 커뮤니티 gradient 대신 expo 버전
npm uninstall react-native-linear-gradient
npx expo install expo-linear-gradient react-native-gifted-charts react-native-svg

npm test -- timeseries     # 변환 로직만 실행
```

### 핵심 코드·설정
- Jest 변환 예외에 차트 패키지 추가 (`jest.config.js`)
```js
const preset = require('jest-expo/jest-preset');
const [defaultPattern, ...rest] = preset.transformIgnorePatterns ?? [];
module.exports = {
  ...preset,
  setupFiles: [...(preset.setupFiles ?? []), '<rootDir>/jest.setup.js'],
  transformIgnorePatterns: [
    defaultPattern.replace(
      'node_modules/(?!',
      'node_modules/(?!react-native-gifted-charts|gifted-charts-core|',
    ),
    ...rest,
  ],
};
```
- Open-Meteo 설정 예시: `path = hourly.temperature_2m`, `xPath = hourly.time`, 표시 형식 = 그래프
