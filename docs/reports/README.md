# 리포트

개발 진행 계획, 진행 현황, 개발 체계 검토 등을 날짜별로 기록한다. `report` 스킬이 작성한다.

> 용어: "이슈"는 GitHub 이슈만 가리킨다. 이 폴더의 문서는 "리포트"라고 부른다.

- 파일명: `YYYY-MM-DD-<주제-kebab-case>.md`
- 형식: 요약 → 현황 → 분석/계획 → 결정 필요 사항
- 기존 리포트의 상황이 바뀌면 새 파일을 만들기보다 해당 리포트에 `## 갱신 (YYYY-MM-DD)` 섹션을 추가한다.
