# WF-01 대시보드 (저충실도)

```
┌──────────────────────────┐
│ 내 대시보드          ⚙️  │
├──────────────────────────┤
│ ┌──────────────────────┐ │
│ │ 서버 상태     [Text] │ │
│ │ OK · 12ms            │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 최근 주문    [Table] │ │
│ │ id │ 금액 │ 상태      │ │
│ │ 12 │ 3000 │ done     │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 방문자  [TimeSeries] │ │
│ │   ╱╲    ╱╲           │ │
│ │ ╱    ╲╱    ╲__       │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 배포 트리거 [Action] │ │
│ │   [ 실행 ]           │ │
│ └──────────────────────┘ │
│                          │
│        [ + 위젯 추가 ]    │
└──────────────────────────┘
```

- 위젯 카드 길게 누르기 → 편집 / 삭제 / 위로·아래로 이동
- 위젯 0개일 때: 안내 문구 + 추가 버튼
