# PRD — 무엇을 만들 것인가

> 사람(기획자) 중심 관리 문서. 사용자 가치와 범위를 정의한다. 구현 방법은 SRS에서 다룬다.

- 버전: v0 (MVP) — **2026-09-23 M1 완료**, 점검: [M1 완료 리포트](../reports/2026-09-23-m1-completion.md)
- 최종 수정: 2026-09-23

## 1. 제품 개요
개인이 여러 외부 API를 위젯 단위로 연결해, 모바일에서 한눈에 보고(입력 위젯) 필요한 요청을 보내는(출력 위젯) 개인용 대시보드 앱.

## 2. 대상 사용자
- 본인(1인 사용자). 개인용 API·자동화 엔드포인트를 가진 개발자.

## 3. MVP 범위

| ID | 기능 | 설명 | 출처 | 우선순위 |
|---|---|---|---|---|
| PRD-001 | 대시보드 구성 | 위젯 추가/삭제/순서 변경, 앱 재시작 후에도 구성 유지 | NB-001 | Must |
| PRD-002 | 데이터 표출 위젯 — 텍스트/테이블 | HTTP API 응답(JSON)의 지정 값을 텍스트 또는 테이블로 표시 | NB-002 | Must |
| PRD-003 | 데이터 표출 위젯 — 시계열 그래프 | JSON 배열을 시간축 선 그래프로 표시 | NB-002 | Must |
| PRD-004 | 데이터 전송 위젯 | 버튼을 눌러 지정 API로 HTTP 요청(POST 등) 전송, 결과 표시 | NB-003 | Must |
| PRD-005 | 위젯 확장성 | 새 위젯 종류를 기존 기능 영향 없이 추가 가능 | NB-004 | Must |
| PRD-006 | API 키 안전 보관 | 인증 키는 기기 보안 저장소에 보관, 위젯 설정에서 참조 | NB-002, NB-003 | Must (부분 — 헤더 입력 UI 미구현, NB-007) |

### M2 성공 기준
- 긴 텍스트·큰 글자 설정이 실기기에서 적용된다.
- 인증이 필요한 공개 API를 헤더 설정만으로 연결해 값을 표시한다.
- 이미지 위젯 2종이 실기기에서 보인다.
- 공개 WebSocket 에코 서버의 메시지가 위젯에 실시간으로 나타난다.
- 조건을 만족할 때 알림이 뜬다(앱 사용 중 기준).
