# NB — Needs Backlog

니즈를 형식 없이 덤핑하는 문서. 정제되면 PRD 항목으로 승격하고 `→ PRD-xxx`를 표기한다.

| 상태 | 의미 |
|---|---|
| `new` | 덤핑만 된 상태 |
| `promoted` | PRD로 승격됨 |
| `hold` | 보류 |
| `dropped` | 폐기 |
